1 Create AWS Account & Enable MFA

If you don't already have an AWS account, set it up now with root-level protection:

  1. Visit aws.amazon.com and click Create an AWS Account.
  2. Enter your Root User Email and an AWS Account Name (e.g. breakout-scanner-prod). Complete email verification.
  3. Enter a strong master password (16+ characters with mixed case and symbols).
  4. Select Personal Account and fill in your contact information.
  5. Payment Information: Enter an international credit/debit card. AWS will charge a temporary $1.00 USD authorization hold (refunded within 3–5 days).
  6. Identity Verification: Verify via SMS phone code.
  7. Select Support Plan: Select Basic Support — Free ($0).
  8. Log in to the AWS Management Console as the Root User.
  9. MANDATORY SECURITY: In the top-right menu, click your account name → Security Credentials → Assign MFA Device. Scan the QR code using Google Authenticator or 1Password.

2 Set a Hard $15/Month AWS Budget Alert

Ensure AWS will immediately notify you via email if your projected monthly spend exceeds $12:

  1. Search for Budgets in the top AWS search bar (or visit AWS Billing and Cost Management → Budgets).
  2. Click Create budget.
  3. Select Cost budget — Recommended and click Next.
  4. Budget Details:
    • Budget name: BreakoutScanner_15DollarGuard
    • Period: Monthly
    • Budget renew type: Recurring budget
    • Budgeting method: Fixed
    • Enter your budgeted amount ($): 15
  5. Click Next to configure Alert thresholds:
    • Threshold 1: 80% ($12.00) of budgeted amount (Actual). Enter your email address.
    • Threshold 2: 100% ($15.00) of budgeted amount (Forecasted). Enter your email address.
  6. Click Next → Create budget. You are now financially insured against surprise cloud charges!

3 Generate SSH Key Pair in Singapore Region

Select your operational home region and create an SSH key pair for server login:

  1. In the top-right region selector dropdown, select Asia Pacific (Singapore) ap-southeast-1.
  2. Search for EC2 and navigate to the EC2 Dashboard.
  3. In the left sidebar under Network & Security, click Key Pairs.
  4. Click Create key pair in the top-right corner.
  5. Configuration:
    • Name: breakout-singapore-key
    • Key pair type: RSA
    • Private key file format: .pem (For OpenSSH on Mac, Linux, and Windows Terminal)
  6. Click Create key pair. Your browser will download breakout-singapore-key.pem.
  7. On your local Mac/Linux computer, move the file to ~/.ssh/ and restrict permissions:
# Run on your local terminal:
mkdir -p ~/.ssh
mv ~/Downloads/breakout-singapore-key.pem ~/.ssh/
chmod 400 ~/.ssh/breakout-singapore-key.pem

4 Launch the EC2 Instance (t4g.small ARM64)

From the EC2 Dashboard in Singapore (ap-southeast-1):

  1. Click Launch Instances.
  2. Name: breakout-scanner-prod
  3. Application and OS Images (Amazon Machine Image):
    • Select Amazon Linux tab → Amazon Linux 2023 AMI (Free tier eligible).
    • Architecture: Click radio button 64-bit (Arm). (Crucial: Do not select x86, or t4g instance type will not appear!)
  4. Instance Type: Select t4g.small (2 vCPU, 2 GiB RAM, ~$12.30/mo) or t4g.micro (1 GiB RAM, ~$6.15/mo).
  5. Key Pair (login): Select breakout-singapore-key.
  6. Network Settings: Click Edit:
    • VPC: Default VPC.
    • Subnet: No preference (Default public subnet).
    • Auto-assign public IP: Enable.
    • Firewall (security groups): Select Create security group:
      • Security group name: breakout-scanner-sg
      • Inbound rule: Type = SSH, Port = 22, Source = My IP (or 0.0.0.0/0 if dynamic home IP).
  7. Configure Storage: Change volume size to 10 GiB, Volume type: gp3.
  8. Review the summary on the right and click Launch Instance.

5 SSH into EC2 & Clone Codebase

Wait 60 seconds until the instance state shows Running and Status check displays 2/2 checks passed. Copy the Public IPv4 address.

# Connect to your EC2 instance (replace YOUR_EC2_PUBLIC_IP)

7 Setup Telegram Bot Token & Chat ID

If you don't already have your Telegram credentials, here is how to get them in 60 seconds:

A. Create a Bot via @BotFather

  1. Open Telegram and search for @BotFather (verified bot).
  2. Send /newbot.
  3. Choose a name (e.g. My Institutional Scanner) and username (e.g. my_breakout_scanner_bot).
  4. BotFather will reply with your HTTP API Token (looks like 7123456789:AAFlm3kP...). Copy it.

B. Find Your Chat ID

  1. In Telegram, start a chat with your new bot and click /start.
  2. Search for @userinfobot in Telegram and click Start. It will instantly reply with your Id (e.g. 987654321).

C. Save to Local .env on EC2

Inside /home/ec2-user/breakout-scanner/, create your private .env file:

cat << 'EOF' > .env
TG_BOT_TOKEN="7123456789:AAFlm3kP..."
TG_CHAT_ID="987654321"
EOF

chmod 600 .env

D. Test Live Alert Dispatch Immediately
